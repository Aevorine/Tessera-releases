**Ваши файлы, пароли, буфер обмена и заметки за одной разблокировкой — плюс набор очистки,
который держит в порядке саму машину под ними.** Ничего не загружается наружу, ничего не
«звонит домой», и ничего не покидает ваш компьютер, если вы сами это явно не настроите.

Бесплатно. Офлайн в первую очередь. Windows 10/11 64-бит, с приложением-компаньоном для
Android для буфера обмена и файлов.

## Загрузка

**→ [Взять последнюю версию](../../releases/latest)**

| Файл | Кому |
| --- | --- |
| `Tessera-Setup.exe` | Установщик Windows — выбор папки, появляется пункт удаления. **Большинству нужен именно он.** |
| `Tessera.exe` | Портативная версия. Работает откуда угодно, включая USB-флешку, реестр не трогает. |

После установки сюда возвращаться не нужно — приложение само находит новые версии.

## Что вы получаете

### Зашифрованное хранилище

- **Файлы** — зашифруйте что угодно в один `.ivault`. По умолчанию постквантовое шифрование
  (AES-256-GCM для содержимого, ключ каждого файла дополнительно обёрнут ML-KEM-1024), либо
  классический AES-256-GCM / ChaCha20-Poly1305. Имена файлов и контрольные суммы лежат *внутри*
  зашифрованного заголовка — украденный контейнер не выдаёт ни того, ни другого.
- **Пароли** — полноценный менеджер, импорт из CSV Chrome/Edge/Firefox, после чего открытый
  CSV безопасно удаляется.
- **История буфера обмена** — автоклассификация (URL / почта / телефон / формула / код /
  текст), закрепление, поиск, чёрный список приложений и глобальная панель `Ctrl+Shift+V`.
- **Заметки** — Markdown с изображениями, вложенные категории, полнотекстовый поиск. Каждая
  заметка возвращает вас туда, где вы остановились. Заметка на 4 МБ показывает первый экран
  примерно за 40 мс.
- **Пять способов разблокировки, достаточно любого** — пароль · код по почте · аутентификатор
  (TOTP) · Windows Hello (лицо / отпечаток / ПИН) · одноразовый ключ восстановления.

### Набор очистки, который говорит правду

- Мусорные файлы, кэши браузеров, следы приватности, остатки драйверов, дубликаты и крупные
  файлы, сжатие диска C:, менеджер автозапуска, контекстное меню, блокировка всплывающих окон
  и 42 небольшие утилиты.
- **Три глубины сканирования** — стандартная (~15 с), глубокая и предельная (все 21 категория).
- **Пробный прогон проходит по настоящему пути кода, не тронув ни байта** и сообщает, сколько
  на самом деле выиграл бы каждый диск.
- **Каждая категория говорит, какую именно «пустоту» она нашла** — действительно чисто,
  заблокировано правами, или вовсе не запускалось — и сколько мест было проверено. «Ничего не
  найдено» и «оно не запускалось» не имеют права выглядеть одинаково.
- **«Освобождено» значит освобождено.** Файлы, отправленные в корзину, считаются *отдельно* от
  реально возвращённого места, а после очистки приложение заново измеряет диск, чтобы вы могли
  сверить его арифметику с тем, что показывает Windows.
- Пять оценок для каждого пункта — *Windows это нужно · драйвер · то, чем вы пользуетесь ·
  необязательное · реклама* — с причиной словами. То, что нужно Windows, заблокировано, и
  бэкенд откажет, даже если его попросят.
- Ключи реестра, элементы автозапуска и обработчики меню **отключаются с резервной копией**, а
  не удаляются. Если экспорт копии не удался, не меняется вообще ничего.

### Телефон ↔ ПК, по вашей собственной локальной сети

Скопируйте на телефоне, вставьте на ПК и наоборот — текст, форматированный текст, код,
математические формулы и изображения сохраняют оформление. Отправляйте файлы или целые папки, с
возобновлением и сквозным шифрованием. Сопряжение по шестизначному коду, QR-коду, ссылке или из
списка ближайших устройств. Трафик остаётся в вашей локальной сети.

### Интерфейс

Единый язык оформления на всех экранах. Восемь акцентных цветов, светлая/тёмная/системная тема,
режим «Простой» или «Профессиональный», и режим комфорта для глаз, который сдвигает цветовую
температуру, **не трогая** цвета состояний — удобство не должно стоить вам способности увидеть,
что пошло не так.

**Шесть языков** — English, 简体中文, Français, Español, Русский, العربية — переключаются где
угодно, включая экран входа.

## При установке: о чём спросят Windows и Android

**Windows.** Сборки подписаны самоподписанным сертификатом, поэтому SmartScreen может
предупредить («Система Windows защитила ваш компьютер»). Нажмите **Подробнее → Выполнить в любом
случае**. Это предупреждение — о том, что сертификат не куплен у коммерческого центра
сертификации, а не о том, что файл изменён.

Встроенные обновления используют тот же ключ подписи: после загрузки приложение проверяет, что
подпись именно *этого* ключа, и **удаляет файл вместо установки**, если это не так. Пути «всё
равно продолжить» не существует.

**Android.** Первое встроенное обновление попросит разрешить установку неизвестных приложений
для Tessera. Android никогда не позволяет загруженному в обход магазина приложению установить
что-либо молча — это финальное подтверждение всегда системное. Обновления требуют совпадающей
подписи, что обеспечивает сам Android, поэтому никто другой не сможет выпустить сборку,
выдающую себя за это приложение.

## Проверьте то, что скачали

GitHub показывает SHA-256 для каждого файла на странице выпуска. Встроенные обновления сверяют
его автоматически; если вы скачивали вручную:

```powershell
Get-FileHash .\Tessera-Setup.exe -Algorithm SHA256
```

```bash
sha256sum Tessera-CrossDevice-*.apk
```

Также можно щёлкнуть по exe правой кнопкой → **Свойства → Цифровые подписи**.

## Системные требования

Windows 10 или 11, 64-бит. Ряд функций привязан к API Windows (Windows Hello, интеграция с
оболочкой, глобальные горячие клавиши). Приложение-компаньон для Android: Android 8.0 или новее.

## Вопросы

**Исходный код открыт?** Пока нет. В этом репозитории только собранные выпуски.

**Оно «звонит домой»?** Нет. Единственный исходящий запрос, который приложение делает само, —
это проверка обновлений в этом репозитории, и её можно перевести в ручной режим.

**Где живут мои данные?** В зашифрованной базе данных, в папке, которую вы выбираете при
настройке. Обновления её не трогают.

**Я потерял пароль.** Воспользуйтесь одноразовым ключом восстановления из настройки. Без него и
без любого из остальных четырёх способов разблокировки хранилище открыть нельзя — в этом и
смысл.
