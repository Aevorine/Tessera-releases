## 你会得到什么

### 一个加密保险库

- **文件** —— 把任何东西加密成单个 `.ivault`。默认抗量子（内容用 AES-256-GCM，每个文件的密钥
  再用 ML-KEM-1024 包一层），也可选经典 AES-256-GCM / ChaCha20-Poly1305。文件名和校验值存在
  **加密头内部**，所以一个被偷走的容器两样都露不出来。
- **密码管理** —— 完整增删改查，可从 Chrome/Edge/Firefox 的 CSV 导入，导入后**明文 CSV 会被安全删除**。
- **剪贴板历史** —— 自动分类（网址 / 邮箱 / 电话 / 公式 / 代码 / 文本）、置顶、搜索、按应用黑名单，
  以及全局 `Ctrl+Shift+V` 面板。
- **笔记** —— 支持图片的 Markdown、多级分类、全文搜索。每篇笔记都会带你回到上次读到的地方。
  一篇 4 MB 的笔记约 40 毫秒就能显示第一屏。
- **五种解锁方式，任意一种就够** —— 密码 · 邮箱验证码 · 验证器（TOTP） ·
  Windows Hello（人脸 / 指纹 / PIN） · 一次性恢复密钥。

### 一套说实话的清理工具

- 垃圾文件、浏览器缓存、隐私痕迹、驱动残留、重复文件与大文件、C 盘瘦身、开机启动项、
  右键菜单、弹窗拦截，以及 42 个小工具。
- **三档扫描深度** —— 标准（约 15 秒）、深度、极限（全部 21 个类别）。
- **预演会走**真实的代码路径**却一个字节都不动**，并告诉你每块盘实际能多出多少空间。
- **每一类都会说清它遇到的是哪一种「空」** —— 真的干净、被权限挡住、还是压根没跑起来 ——
  以及它为此检查了多少个位置。「什么都没找到」和「它根本没运行」不许长得一样。
- **「已释放」就是真的释放了。** 进了回收站的文件与真正收回的空间**分开计数**，
  而且清理后应用会重新测量磁盘，让你能拿它的算术去对 Windows 报的数。
- 每一项都带五档判断 —— *Windows 需要它 · 驱动 · 你在用的东西 · 可选 · 推广垃圾* —— 并写明理由。
  Windows 需要的项是锁死的，就算前端硬传上来后端也拒绝执行。
- 注册表项、启动项和菜单处理器一律是**禁用 + 备份**，从不删除。备份导出失败时，什么都不会改。

### 手机 ↔ 电脑，走你自己的局域网

手机上复制，电脑上粘贴，反过来也行 —— 文本、富文本、代码、数学公式和图片都保留格式。
发送文件或整个文件夹，断点续传、端到端加密。配对方式有六位数字码、二维码、可分享的链接，
或者从附近设备列表里挑。流量只在你的局域网内。

### 界面

全应用一套设计语言。八种强调色、浅色/深色/跟随系统、简洁或专业两档信息密度，
以及一个**只调色温、不动状态色**的护眼模式 —— 看着舒服不该以「看不清哪里出错」为代价。

**六种语言** —— English、简体中文、Français、Español、Русский、العربية —— 随处可切，登录界面也能切。

## 在找这些的替代品？

平时要装三四个软件才能覆盖的事，Tessera 一个离线应用就够了：

- **CCleaner / 火绒安全 / Wise Disk Cleaner** —— 垃圾文件、浏览器数据、注册表残留、
  启动项管理、重复文件、C 盘瘦身。每一条都写清楚它是什么、删了你会失去什么，
  而且可以先干跑一遍看会发生什么再决定。
- **KeePass / Bitwarden / 1Password** —— 本地密码管理器，内置动态验证码。
  不用注册账号、不过第三方服务器、没有订阅费。
- **VeraCrypt / 7-Zip AES 加密** —— 文件与文件夹加密，默认抗量子。
- **Ditto / 剪贴板管家** —— 剪贴板历史，支持搜索、置顶和全局快捷键。
- **Obsidian / 各类速记软件** —— 支持图片和全文搜索的 Markdown 笔记，落盘即加密。
- **AirDroid / LocalSend** —— 只走局域网的剪贴板与文件同步，手机平板都能用。

免费开源（AGPL-3.0），Windows 10/11 64 位。

## 安装时 Windows 和安卓会问什么

**Windows。** 安装包用自签名证书，SmartScreen 可能会拦一下（「Windows 已保护你的电脑」）。
点**「更多信息」→「仍要运行」**。那个警告说的是「证书没向商业 CA 买过」，不是「文件被改过」。

应用内更新用同一把签名密钥：下载完成后核对签名是不是**这一把**，
**对不上就直接删掉、绝不安装**。不存在「这次先算了」的降级路径。

**安卓。** 第一次用应用内更新时，系统会请你为 Tessera 打开「允许安装未知应用」。
安卓不允许旁加载的应用静默安装任何东西 —— 最后那个确认框永远由系统弹出，应用绕不过去。
覆盖安装要求签名一致，这是安卓系统强制的，所以别人冒充不了这个应用。

## 常见问题

**源码公开吗？** 目前不公开。这个仓库只存放发布产物。

**它会回连服务器吗？** 不会。应用唯一主动发起的对外请求是向这个仓库检查更新，而且可以改成手动。

**我的数据存在哪？** 存在一个加密数据库里，位置由你在初次设置时选。更新不会碰它。

**我把密码忘了。** 用初次设置时给你的一次性恢复密钥。如果它也没了、另外四种解锁方式也都用不了，
那这个保险库就打不开了 —— 这正是它存在的意义。
