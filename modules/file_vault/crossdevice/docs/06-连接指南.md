# 连接指南：怎么把手机、平板和电脑连起来

这份是操作说明，不是设计文档。照着做就行。

---

## 0. 开始之前

**两台设备必须在同一个局域网里。** 也就是连同一个 Wi-Fi，或者电脑插网线、手机连同一个路由器发出的 Wi-Fi。

判断方法：两台设备的 IP 地址前三段一样。手机在「设置 → WLAN → 当前网络」里看，电脑在跨设备面板顶部看端口那一行旁边。比如手机 `192.168.1.20`、电脑 `192.168.1.10`，前三段都是 `192.168.1`，那就在同一个网里。

> **开着 VPN / 代理会怎样？** 应用会自动跳过 VPN 的虚拟网卡，只公布真实的局域网地址，所以一般不用关。但如果 VPN 开了「全局模式」并且拦截了局域网流量，那就得关掉或者把局域网段加进直连规则。

---

## 1. 最快的方式：手机扫电脑

1. **电脑**：打开 Tessera → 左侧「跨设备 → 设备与同步」→ 在「添加设备」里点 **生成配对码**。屏幕上会出现一张二维码。
2. **手机**：打开 Tessera 跨设备 App → 点 **扫码配对** → 把二维码放进取景框。
3. 两边各自弹出一组 **六位数字 + 六个表情**。
4. **核对它们完全一致**，然后两边都点「一致」。

完成。设备列表里会出现对方。

### 第 4 步不能跳过

设备名是可以随便伪造的，安全码是唯一能证明"我连上的确实是对面那台"的东西。两边显示的不一样，说明中间有人在转发——这时候选「不一致」，配对会立即作废。

### 配对码是一次性的

用过就失效，60 秒不用也失效。所以截图分享一张旧的二维码没有任何用处，也不构成风险。

---

## 2. 手机不方便扫码时：粘贴配对码

同样是电脑点「生成配对码」，但改用二维码下面的 **复制配对码** 按钮，把那串 `CB1:...` 发给手机（微信、QQ、邮件都行），手机上点 **粘贴配对码** 贴进去。

之后同样要核对安全码。

> 配对码本身只包含公钥和一次性令牌，**不含任何私钥**，通过聊天软件传递不会泄露你的设备身份。

---

## 3. 电脑连电脑

两台电脑都能显示二维码但都没摄像头，用复制/粘贴那条路：一台点「生成配对码 → 复制配对码」，另一台在「输入对方的配对码」里粘贴。

---

## 4. 连上之后

### 传剪贴板

在任意一台设备上复制东西，然后：

- **电脑 → 其他设备**：跨设备面板点「发送剪贴板」
- **手机 → 其他设备**：App 里点「发送剪贴板」，或者在任意应用里选中文字 → 分享 → 选 Tessera

公式和物理符号会原样到达（`E = mc²`、`m/s²`、`θ̇`、`∑∫√`），因为每次复制会同时带上纯文本、富文本、LaTeX 和图片多种形式，粘贴时由目标应用挑它认识的那种。

### 传文件

- **电脑**：跨设备面板 → 勾选目标设备 → 「发送文件」
- **手机**：App 里点「发送文件」，或者在相册/文件管理器里选中 → 分享 → 选 Tessera

不勾选设备就发给所有在线设备。一对多时每台设备各走各的传输，慢的不拖累快的，某一台失败也不影响其他。

### 收到的文件存哪

两端都可以自己选：

- **电脑**：跨设备面板 → 选项 → 「收到的文件保存到」旁边的「更改」
- **手机**：App 首页最下面 → 「收到的文件存到」旁边的「更改」

选完会立刻试写一个探针文件，选到只读盘或已拔出的 U 盘会当场报错，不会等传了几个 G 才失败。

### 改设备名

跨设备面板 → 本机 → 设备名旁边的铅笔图标。改完**不用重连**，已配对的设备最多 10 秒就会显示新名字。

---

## 5. 断开之后会自动连回来

手机锁屏、电脑睡眠、切换 Wi-Fi、路由器重启——都不用管，也没有「重连」按钮。

重连是几条路同时发车：上次成功的地址、历史地址、以及局域网发现当前报出来的地址，谁先接上用谁。局域网内通常远小于一秒。因为发现是实时的，对方换了 IP（换 Wi-Fi、重新拿 DHCP、换网段）照样能找到。

**长期设备**才会自动重连。配对时选了「临时」的设备到期即失效，这是刻意的区分。

---

## 6. 连不上时按顺序排查

| 现象 | 检查 |
|---|---|
| 扫码后一直转圈 | 两台设备是不是在同一个 Wi-Fi？手机连的是不是自己的热点？ |
| 设备列表里是「离线」 | 电脑端 Tessera 是否在运行（托盘里能看到）？ |
| 换了 Wi-Fi 之后连不上 | 等 10~30 秒，发现层会重新扫描。仍然不行就在两端各点一次「刷新」。 |
| 公司/学校网络 | 很多这类网络开了 **AP 隔离**，同一个 Wi-Fi 下的设备之间互相不通。换成手机热点试一下就能确认是不是这个原因。 |
| 装了 VPN / 加速器 | 应用会自动跳过 VPN 虚拟网卡，但全局模式可能拦截局域网流量。临时关掉试一下。 |
| Windows 弹过防火墙询问并且点了「取消」 | 控制面板 → Windows Defender 防火墙 → 允许应用通过 → 找到 `tessera-crossdevice` 勾上「专用网络」。 |

### 用手机热点绕过网络限制

公司、学校、酒店的 Wi-Fi 经常禁止设备互访。最快的验证和绕过办法：

1. 手机开热点
2. 电脑连这个热点
3. 重新配对（或者等已配对设备自动连上）

这条路走的是手机自己的局域网，不受路由器策略影响。

---

## 7. 安全上你需要知道的

- 每台设备有自己的长期密钥，首次运行时生成，**不是**硬件序列号或 IMEI（那些撤销不了）
- 在同一个网里不代表任何权限：每次连接都要重新验证配对时确认过的那把公钥
- 对方公钥变了会明确报警，不会悄悄接受
- 每次连接协商一次性密钥，所以录下今天的流量、日后偷到设备密钥也解不开
- 收到的 `.exe` / `.msi` / `.apk` 一律当普通文件保存，**从不自动运行或安装**
- 随时可以在设备列表里撤销任何设备，撤销立即生效且不可挽回
